# 📊 E-Commerce Sales Dashboard | Power BI

## 📌 Overview

This project is an interactive **Power BI dashboard** built using an e-commerce sales dataset. It provides insights into sales performance, profit, quantity sold, and customer purchasing patterns through dynamic visualizations and filters.

## 🚀 Features

* 💰 Total Sales KPI
* 📈 Total Profit KPI
* 📦 Total Quantity Sold
* 🛒 Average Order Value (AOV)
* 📅 Monthly Profit Analysis
* 🌍 Region-wise Analysis
* 📊 Product-wise Profit Analysis
* 👥 Customer-wise Sales Analysis
* 🎯 Interactive Quarter and Region Filters

## 🛠️ Tools & Technologies

* Microsoft Power BI
* DAX (Data Analysis Expressions)
* Data Modeling
* CSV Datasets
* Data Visualization

## 📂 Project Files

* `Ecommerce_Sales.pbix` - Power BI dashboard
* `sales_orders.csv` - Orders dataset
* `order_details_with_profit.csv` - Order details with profit calculations
* `Dashboard.png` - Dashboard preview
